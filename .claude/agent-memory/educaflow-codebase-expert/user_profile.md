Jonas (jonasbarros98@gmail.com) is the developer and owner of EducaflowOne.

- Built a full SaaS product (Django + vanilla JS frontend) for private English teachers in Brazil
- The target user is a freelance/private language teacher (professora) who manages students, lessons, billing, and homework
- The primary real-world user appears to be "Cini" (an English teacher — hence the repo name "Cini English"), though the platform is sold as a multi-tenant SaaS
- Deployed on Railway at https://www.educaflowone.com.br
- Handles Stripe subscription billing, Google OAuth, email via Resend
- Code style: Python/Django backend with REST API consumed by vanilla HTML/JS templates (no React/Vue)
