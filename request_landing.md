# Request: Landing Page Perfeita — EDUCAflowOne

Use the prompt below **exactly as your creation brief**.

---

You are a senior conversion-focused landing page strategist + copywriter + UI engineer.

Create a **high-converting, premium-looking landing page** for my product:

- **Product name:** EDUCAflowOne
- **Primary audience:** private teachers/tutors (1:1 and small studios)
- **Market language:** Brazilian Portuguese (PT-BR)
- **Primary goal:** maximize free-trial signups
- **Secondary goals:** increase trust, explain value fast, reduce friction

## 1) Core product context (must be reflected accurately)

EDUCAflowOne is an all-in-one management platform for private teachers:

- student management
- calendar and class scheduling
- lesson planning
- financial control (invoices, pending payments)
- student materials management ("Arquivos")
- student area/portal

Key recent feature to highlight: **Arquivos** (teacher file library)

- Teacher can store and organize files/links
- Search/filter/tag materials
- Send material to student quickly
- Reuse content without re-uploading

## 2) Positioning and messaging goals

The page should communicate:

- "Stop running your teaching business on WhatsApp + spreadsheets"
- "Everything in one organized place"
- "Professionalize your operation without complexity"

Tone:

- premium, trustworthy, practical, clear
- warm but not childish
- modern SaaS language, but human and easy to understand

Avoid:

- generic AI buzzwords
- exaggerated claims without support
- overused startup cliches

## 3) Conversion requirements

Design the page to convert with:

- strong hero with immediate value proposition
- visible CTA above the fold
- multiple CTA repeats across the page
- objection handling (price/complexity/time)
- social proof section
- feature-benefit mapping (not just feature list)
- final CTA section with urgency/light friction removal

Primary CTA text ideas:

- "Começar grátis por 7 dias"
- "Criar minha conta agora"

No credit card mention (if true): include if it helps conversion.

## 4) Mandatory sections (in this order)

1. **Hero**
   - eyebrow label (not cliché)
   - clear headline
   - support subheadline
   - primary + secondary CTA
   - product visual (dashboard mock/screenshot area)

2. **Pain points** (current chaos)
   - WhatsApp, notebook, spreadsheet fragmentation
   - missed payments, disorganized lessons, wasted time

3. **Value bridge**
   - short transition from pain to solution

4. **Core features** (visual blocks)
   - Agenda / Calendar
   - Financeiro
   - Alunos
   - Planejamento
   - Arquivos (highlight strongly)

5. **How it works** (3 simple steps)

6. **Proof/trust**
   - testimonials style cards
   - trust stats (placeholder realistic numbers allowed)

7. **Pricing teaser**
   - show plan tiers briefly (Basic / Premium / Platinum)
   - CTA to pricing/signup

8. **FAQ**
   - 6-8 high-intent questions

9. **Final CTA block**
   - clear trial action + confidence copy

10. **Footer**
   - brand, links, contact points

## 5) Design direction (very important)

Create a design that feels:

- premium SaaS, clean, light background
- subtle gradients, soft shadows, rounded components
- strong hierarchy, whitespace, polished typography
- mobile-first responsive behavior

Suggested visual style:

- modern cards
- sticky nav
- smooth reveal animations (subtle)
- polished button system (primary, ghost)
- screenshot cards with hover zoom in desktop

Do NOT create something that looks like a generic template.

## 6) Technical output requirements

Provide:

1. Full HTML (single file)
2. Embedded CSS and JS (or well-structured split, but copy-paste ready)
3. Semantic and accessible markup
4. Responsive behavior for desktop/tablet/mobile
5. Clean class naming and readable structure

Also include comments in code blocks marking sections:

- HERO
- PAIN
- FEATURES
- HOW IT WORKS
- TESTIMONIALS
- FAQ
- FINAL CTA

## 7) Copy quality requirements

Copy must be:

- specific
- concrete
- benefit-first
- audience-aware (private teachers)
- not robotic

Use PT-BR naturally.

Examples of style target:

- "Organize alunos, aulas e pagamentos em um só lugar."
- "Menos tempo em planilhas. Mais tempo ensinando."

## 8) SEO and metadata

Include:

- title tag
- meta description
- Open Graph basic tags
- clear H1/H2 structure

## 9) Final deliverable format

Return in this exact order:

1. Strategic summary (short)
2. Section-by-section conversion rationale
3. Full code

If possible, also provide:

- 3 A/B variants for hero headline
- 3 A/B variants for main CTA text
